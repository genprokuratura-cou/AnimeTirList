# 🍁 ANIME TIER LIST — Осенний неоновый рейтинг с 3D

Красивый и функциональный веб-сайт для создания и управления вашим персональным рейтингом аниме. Сайт выполнен в стильном осеннем неоновом дизайне с продвинутыми 3D-эффектами и анимациями.

## ✨ Особенности

### 🎨 Дизайн
- **Осенняя тематика** — тёплые цвета, падающие листья, неоновые акценты
- **3D-анимации** — объёмные буквы тиров (S, A, B, C, D) с эффектом параллакса
- **Динамический фон** — частицы Three.js, светящиеся орбы, градиентные переходы
- **Адаптивность** — полностью работает на мобильных устройствах

### 🎯 Функционал
- **Навигация по тирам** — боковая панель с кнопками S, A, B, C, D для быстрого переключения
- **Drag & Drop** — перетаскивание карточек между тирами мышью
- **Поиск** — мгновенный поиск по названию аниме
- **Редактирование** — изменение названия карточки прямо на лету
- **Импорт/Экспорт** — сохранение и загрузка списка в формате JSON
- **Случайный выбор** — функция "Что посмотреть?" для выбора случайного аниме
- **Авто-сохранение** — все данные сохраняются в localStorage браузера

### 🔥 Эффекты
- **Золотой салют** — праздничный эффект при добавлении аниме в S-тир
- **Неоновое свечение** — каждая карточка светится цветом своего тира
- **Параллакс фона** — реакция на движение мыши
- **Анимированные листья** — падающие осенние листья на фоне
- **🐲 Эффект дракона** — при наведении на кнопки тиров (S, A, B, C, D) появляется уникальный дракон:
  - **S** — 👑 Королевский Дракон с золотым пламенем
  - **A** — 🔮 Мистический Дракон с розовым сиянием
  - **B** — ❄️ Ледяной Дракон с голубыми искрами
  - **C** — 🌿 Природный Дракон с зелёными частицами
  - **D** — 🔥 Огненный Дракон с красным пламенем

## 🚀 Быстрый старт

### Вариант 1: Открыть локально
1. Скачайте файл `index.html`
2. Откройте его в любом современном браузере (Chrome, Firefox, Edge, Safari)
3. Готово! Сайт работает без сервера

### Вариант 2: Запустить через локальный сервер
```bash
# Если у вас установлен Python 3
python3 -m http.server 8000

# Или через Node.js (npx)
npx serve .

# Затем откройте в браузере: http://localhost:8000
```

## 📖 Как пользоваться

### Добавление аниме
1. В форме "Добавить аниме" введите название
2. Выберите тир (ранг) от S до D
3. Добавьте изображение:
   - **Ссылкой**: вставьте URL картинки (должна заканчиваться на .jpg, .png и т.д.)
   - **Файлом**: нажмите "Выбрать файл" и загрузите с устройства
4. Нажмите "✨ Добавить"

### Управление карточками
- **Перетаскивание**: зажмите карточку мышью и перетащите в другой тир
- **Редактирование**: нажмите на карандаш ✎ на карточке, чтобы изменить название
- **Удаление**: нажмите на крестик ✕, чтобы удалить карточку

### Навигация по тирам
Слева расположена вертикальная панель с кнопками:
- **🌐** — показать все тиры сразу
- **S** — только легендарные аниме (золотой)
- **A** — великолепные (розовый)
- **B** — отличные (голубой)
- **C** — средние (зелёный)
- **D** — слабые (красный)

При клике на кнопку происходит плавный 3D-переход к выбранному тиру.

### Поиск и фильтрация
Введите название в поле поиска в верхней панели — карточки будут фильтроваться мгновенно.

### Экспорт/Импорт
- **Экспорт**: нажмите "⬇ Экспорт" — скачается файл `anime-tier-list.json`
- **Импорт**: нажмите "⬆ Импорт" и выберите ранее сохранённый JSON-файл

### Случайный выбор
Нажмите "🎲 Что посмотреть?" — сайт предложит случайное аниме из вашего списка.

```css

  --gold1: #fff3c4;           /* Золотой градиент 1 */
  --gold2: #ffd75e;           /* Золотой градиент 2 */
  --txt: #f5ecdf;             /* Цвет текста */
}
```

## 💾 Хранение данных

Все данные сохраняются в **localStorage** вашего браузера:
- Ключ: `animeTierList_v1`
- Формат: JSON-массив объектов
- Лимит: ~5-10 МБ (зависит от браузера)

**Важно**: Данные хранятся только в вашем браузере! Для переноса на другое устройство используйте экспорт/импорт.
